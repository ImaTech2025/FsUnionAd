模板插屏
简介
基本信息

插屏广告样式新上线，更丰富的创意内容，更吸睛的呈现样式，更灵活的组件配置，助力提升流量商业价值。

适用场景

在应用停顿点，适合投放这类广告。插屏广告支持图片、视频物料。

横版	竖版
	
接入提示
集成参考类：ExpressInterstitialActivity
创建广告实例，注册ExpressInterstitialListener来监听广告的各种行为
广告在回调onADLoaded后，才可调用show接口展示插屏广告
注意show成功后需要重新load新的广告，同一条广告不能重复曝光
可以通过isReady接口来判断广告是否有效且缓存成功。
主要API
ExpressInterstitialAd
方法名	方法介绍
ExpressInterstitialAd(Context context, String adPlaceId)	默认构造函数：传入当前页面的context，adPlaceId为广告位id
load()	加载模板插屏广告
show()	展现模板插屏广告
show (Activity activity)	使用传入的Activity展现广告
setLoadListener(ExpressInterstitialListener listener)	设置广告行为相关的listener
setDownloadListener(InterAdDownloadWindowListener listener)	设置下载行为相关的listener
setDialogFrame (boolean useDialogFrame)	下载广告是否出下载弹窗
getECPMLevel()	获取广告价格，单位：分
biddingSuccess(LinkedHashMap<String, Object> secondInfo, BiddingListener listener)	当百度竞价成功时调用此方法，反馈二价信息
@param secondInfo 竞价成功后的额外信息
@param listener 竞价listener，建议注册
biddingFail(LinkedHashMap<String, Object> winInfo, BiddingListener listener)	媒体调用反馈竞价失败及原因
@param winInfo 竞胜方信息
@param listener 竞价listener，建议注册
setBidFloor(int bidFloor)	设置广告的底价，单位：分（仅支持bidding模式）
isReady()	判断广告是否可用(缓存成功且未过期为true)
destory()	销毁插屏广告
ExpressInterstitialListener
方法名	方法介绍
onADLoaded()	广告加载成功
onAdFailed(int errorCode, String message)	广告请求失败
onAdClick()	广告被点击
onAdClose()	广告被关闭
onNoAd(int errorCode, String message)	无广告返回
onADExposed()	广告曝光成功
onADExposureFailed()	广告曝光失败
onAdCacheSuccess()	广告素材缓存成功
onAdCacheFailed()	广告素材缓存失败
onLpClosed()	落地页关闭
InterAdDownloadWindowListener
方法名	方法介绍
adDownloadWindowShow()	下载弹窗展示回调
adDownloadWindowClose()	下载弹窗关闭回调
onADPrivacyClick()	下载广告 隐私声明点击回调
onADPrivacyClose()	下载广告 隐私声明关闭回调
onADPermissionShow()	下载广告 权限弹窗展示回调
onADPermissionClose()	下载广告 权限弹窗关闭回调
InterstitialAdDislikeListener
方法名	方法介绍
interstitialAdDislikeClick()	负反馈点击回调
