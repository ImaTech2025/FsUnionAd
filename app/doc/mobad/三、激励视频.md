激励视频
简介
激励视频广告是用户通过观看短视频，获取应用内奖励（免广告，任务奖励，游戏金币）等，具体场景由开发者定义。 目前SDK已支持请求时自动判断横竖屏，开发者无需额外配置即可自动适配屏幕方向。样式图效果如下：

接入提示
集成参考类：RewardVideoActivity
激励视频广告推荐缓存成功后再播放 ，避免卡顿。需提前预加载load，缓存成功后，调用show播放。可以通过isReady接口判断是否缓存成功
广告存在有效期，需要一定时间（2小时，该值为非固定值）内展现，可以通过isReady判断是否过期。
单次请求的广告不支持多次展现。下次展现前需要重新预加载视频，可以在点击关闭操作后重新预加载新广告。
监听展现失败onAdFailed做异常流程处理。

二段激励
**说明：**即在激励视频场景中，以转化任务的形式，通过对原有的激励金进行翻倍或膨胀，用额外增加出的奖励来激发用户再进一步发生转化

奖励类型		奖励过程		
膨胀奖励	翻倍奖励	前卡-任务引导	中卡-中途返回	后卡-奖励发放
				
整体链路:

广告渲染：为保障用户体验和媒体调控的灵活性，二段激励广告支持媒体在请求维度设置本次广告是否可出二段激励，以及返回对应的二段奖励信息
奖励发放：若用户发生二段激励转化，则会单独下发二段激励奖励回调，由媒体进行二段激励奖励发放

接入示例：
// 创建激励视频广告对象时，注册激励视频广告监听
mRewardVideoAd = new RewardVideoAd(context ,adPlaceId, new RewardVideoAd.RewardVideoAdListener {
    /**
     * 激励视频奖励回调
     * @param rewardVerify 奖励验证结果，YES为成功
     * @param rewardInfo 奖励信息，如果是二段激励，则包含发放奖励的类型
     *                   key: reward_type 奖励类型  value: 0: 普通奖励，1:膨胀奖励、2: 翻倍奖励
     */
    @Override
    public void onRewardVerify(boolean rewardVerify, Map<String, Object> rewardInfo) {
        // do something
    }

    // 其他回调接口
    ...
});

// 【可选】若要使用二段激励功能，需要在展现广告前，设置好奖励的信息，包括基础奖励信息，以及二段激励的类型和激励后的最终奖励信息
RewardVideoRewardInfo rewardInfo = RewardVideoRewardInfo.builder()
    // 选择奖励类型，1:膨胀奖励、2: 翻倍奖励
    .setRewardType(new Random().nextInt(2) + 1)
    // 普通奖励值，输入数字，最多支持展示5位
    .setBasicReward("9999")
    // 普通奖励单位，最多支持展示3位
    .setBasicUnit("金币")
    // 二段奖励值，输入数字，最多支持展示5位
    .setAdvancedReward("99999")
    // 二段奖励单位，最多支持展示3位
    .setAdvancedUnit("金币")
    // 当奖励类型为翻倍奖励时，需要输入奖励的倍数
    .setMultiple("2")
    .create();
// 【可选】设置二段激励的奖励信息
mRewardVideoAd.setRewardInfo(rewardInfo);
// 调用show()展示激励视频...
mRewardVideoAd.show();

激励视频S2S（服务端奖励验证）接入说明
服务端奖励验证
服务端奖励验证用于帮助媒体判定是否提供奖励给观看广告的用户，当用户成功看完广告时，会向媒体在union平台中配置的验证接口发送验证请求，并携带广告和媒体自定义参数信息，由媒体来判断此次观看是否给用户发放奖励。百青藤服务端不会主动干预奖励的成功与失败。

服务端回调说明
百青藤服务端会发送请求至媒体在百青藤广告位配置的URL服务端，拼接参数如下：

请求域名 ：百青藤配置

请求类型 ：GET

请求参数：

字段名称	字段含义	字段类型	备注
trans_id	交易id	string	签名
user_id	用户id	string	用户唯一id，媒体调用SDK透传
apid	广告位id	string	广告位id
appid	应用id	string	appsid
extra	Extra	string	媒体自定义参数，SDK透传
sign	签名	string	验签
签名生成方式：

sign = sha256(trans_id:secret)
trans_id:交易id

secret：百青藤平台创建代码位时生成的密钥

接口返回：

字段名称	字段含义	类型	备注
isValid	校验结果	string	判定结果，是否发放奖励1，发放0，不发放
code	状态码	int	0表示success，其它code可不用解析
msg	状态说明	string	code对应说明
